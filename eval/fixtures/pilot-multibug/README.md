# textstats

Word counting, averages, search and slug normalisation over plain text.

## Layout

- `textstats/counting.py` - splitting text into words
- `textstats/averages.py` - mean word length
- `textstats/search.py` - finding every occurrence
- `textstats/normalise.py` - slugs
- `textstats/report.py` - formatting a summary
